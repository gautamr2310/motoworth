# MotoWorth M2.1 — India Catalogue Completeness Audit

Date: 2026-09-21

## Scope
M2.1 expands the M2 catalogue from a 31-brand / 273-model seed into a broader India-market catalogue covering current, recent-discontinued and historically relevant models. Model names are kept at model/generation level where that distinction matters for used-bike valuation.

## Data policy
- India-market presence is the inclusion criterion; global-only models are not intentionally added as production references.
- Catalogue presence does not imply a verified price.
- Unknown prices remain unknown; no synthetic price is inserted.
- Historical price references are only marked verified where a source supports the India-market price and date.
- Current model pricing remains governed by the existing verified-reference layer.

## Key historical validation
Triumph Street Scrambler 900 (2019) is explicitly represented with the 2019 India launch reference of ₹8.55 lakh ex-showroom and source/date provenance.

## Quality gates
- JSON parse: PASS
- Duplicate model IDs: 0
- Orphan model records: 0
- Catalogue selector uses dynamic model/brand counts from the catalogue
- `catalogue.v2.json` and `bikes.json` synchronized
- Existing valuation engine files unchanged
- Existing state-tax/on-road logic unchanged
- Existing mobile UI unchanged

## Important distinction
M2.1 is a catalogue-completeness milestone, not a claim that every model has a source-backed price. Price/spec coverage is intentionally separated from catalogue existence so MotoWorth never fabricates valuation anchors.
