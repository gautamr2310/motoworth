# MotoWorth Mobile Optimization

Mobile-first responsive pass applied to the current V15 + M2 + On-Road + final-logo baseline.

## Scope
- Compact mobile header with the current MotoWorth logo.
- Shorter, readable hero section.
- One-column calculator layout below 760px.
- Touch-friendly 44–46px controls.
- iOS-friendly 16px form controls to avoid automatic input zoom.
- Stacked bike summary and responsive result cards.
- Responsive today/registration/decision sections.
- Reduced horizontal padding and overflow risk on small screens.
- No valuation mathematics, catalogue data, state-tax logic, PDF logic, or API behavior changed.

## Breakpoints
- <= 760px: primary mobile layout.
- <= 380px: compact/small-phone refinements.
