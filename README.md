# MotoWorth — V15 + M2 + State On-Road Master

This package is the consolidated MotoWorth master build.

## Included
- V15 Option 4 UI and email-gated PDF report flow.
- M2 catalogue: 31 brands, 273 models, 28 variants.
- State-based on-road valuation: ex-showroom → verified state road tax → registration fee → on-road reference → valuation adjustments.
- Current supporting data files kept internally aligned with the catalogue.
- The calculator blocks calculation when a selected state does not yet have a verified tax profile; it does not silently substitute ex-showroom as the valuation basis.

## Deployment
Deploy the entire package as one repository snapshot. Do not mix individual files from older MotoWorth ZIPs.
